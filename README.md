# Martindale Lawyer Directory API examples (retired)

> **I've retired Martindale Lawyer Directory API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For finding lawyers, use my **[Google Local Services API](https://apify.com/johnvc/google-local-services-api?fpr=9n7kx3)** instead, and start from its example repo, [Apify-GoogleLocalServices-API](https://github.com/johnisanerd/Apify-GoogleLocalServices-API).

## Use instead

- **[Google Local Services API](https://apify.com/johnvc/google-local-services-api?fpr=9n7kx3)**: Google Screened lawyers (personal injury, immigration, DUI and more) with ratings, reviews and phone numbers. Example repo: [Apify-GoogleLocalServices-API](https://github.com/johnisanerd/Apify-GoogleLocalServices-API).
- **[Google Maps Places Scraper](https://apify.com/johnvc/google-maps-places-api?fpr=9n7kx3)**: law firms on Google Maps with address, phone, website, rating and hours. Example repo: [Apify-Google-Maps-Places-API](https://github.com/johnisanerd/Apify-Google-Maps-Places-API).
